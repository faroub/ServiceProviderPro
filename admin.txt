## 📱 In-app admin screens (already built)
Once logged in as admin, you land in the mobile app with two dedicated screens:

1. **`/admin/verification`** — Provider verification queue
   - See pending provider verification requests (national ID, business docs, selfies).
   - Approve or reject each request; approved providers get a green "Verified" badge, rejected get a note.

2. **`/admin/flags`** — Abuse/report queue
   - Auto-flagged providers (e.g., multiple no-show reports, low ratings, fraud complaints).
   - Manually clear a flag once reviewed, or take action (deactivate).

## 🌐 Admin backend endpoints
| Endpoint | Purpose |
|---|---|
| `GET /api/admin/verification/pending` | List providers awaiting verification |
| `POST /api/admin/verification/{id}/approve` | Approve provider |
| `POST /api/admin/verification/{id}/reject` | Reject provider |
| `GET /api/admin/flags` | List all flagged providers |
| `POST /api/admin/flags/{id}/clear` | Clear a flag |
| `POST /api/admin/backfill/wilaya` | Assign default wilaya to legacy accounts |

## 📊 What's currently *missing* for a great admin experience

There's no unified **overview dashboard** — you'd have to jump between screens to see totals. Also no way to:
- View KPIs (total users, providers, bookings, revenue, GMV)
- Deactivate a user / reset a phone number from the app
- Search for a specific user or booking
- See platform commission earned this month
- Filter reports by reason / severity
- Broadcast a push notification to users
